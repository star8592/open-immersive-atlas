# Open / Private Boundary · 开放与私有边界

**Public repository / 公开范围**: Original bilingual descriptions, verified public links, research notes derived from openly accessible sources, scripts for catalog validation and browsing. / 公开原创中英分析、公开证据链接、目录工具。

**Never publish / 严禁公开**: unpublished original game code; unreleased commercial plans or private cost models; private repo paths/content; client data or assets; copyrighted models, screenshot downloads or videos without rights; API keys, cookies, authentication tokens, emails, personal information, internal Agent prompts, raw customer records. / 自研游戏源码、未发布商业策略、客户数据、账户凭证、内部提示词、未经许可素材一律不得入库。

**External project rights / 第三方版权**: Links are citations, not endorsements or mirrors. Each source retains its own license. Check code, weights, datasets, generated assets, audio and service terms separately. A public product page does not grant code/asset reuse rights. / 收录不等于转授权；源码许可与模型权重、素材和服务条款是不同层级。

**Claims / 证据**: Document precisely whether an author reported a technique, code was inspected, or a benchmark was locally reproduced. Marketing claims are not benchmarks. / 区分作者技术笔记、源码阅读与真实复现。

If a secret or private file is mistakenly committed, rotate/revoke credentials immediately and remove sensitive history with proper incident handling rather than only deleting the current file. / 如果误提交秘密，立即撤销/轮换凭证并处理 Git 历史，而不是只删当前文件。
