Why this lab exists / 为什么做这个实验？

A gorgeous static background is not a playable 3D world. This original demo contains real height-field geometry, independent terrain chunks, camera-distance LOD, edge skirts that cover cracks, procedural granular material, and a visible performance HUD. / 静态背景图不等于真实可探索空间。这个原创实验包含可旋转的真实地形几何、独立瓦片、距离 LOD、边缘遮缝、程序化颗粒材质与性能数据。

LOD Camera-dependent mesh density / 相机距离决定网格密度
Geometry Real vertex positions and normals / 真实顶点与法线
Measurement CPU frame-interval p95, not GPU time / 此处 p95 是帧间隔而非 GPU 帧时

Original public educational implementation, no third-party model or private game assets. Collision/navmesh and GPU profiling are deliberately out of scope in this first lab. / 原创教学示例，不包含第三方模型或私有游戏资产；物理碰撞、导航网格与 GPU 专用计时仍属后续实验。
