Press “Measure sequentially”: 40 warm-up + 120 browser-frame samples per renderer, then 24 asynchronous GPU pass queries where supported. / 顺序测试：每种后端预热 40 帧、采集 120 帧，再对支持计时的 GPU 进行 24 次真正渲染通道计时。

Three different metrics / 三种不同指标。 JS render/submit-call time measures synchronous CPU-side calls, while rAF p95 measures browser frame cadence. GPU pass p95 uses WebGPU timestamp-query or WebGL2 disjoint timer extension only when supported; it measures GPU pass work, not presentation, uploads or entire-game frame time. Unavailable, disjoint and timed-out samples are explicitly excluded and reported. / CPU 提交、浏览器帧间隔、GPU 通道执行耗时分别统计；计时不支持时显示“不支持”，不得伪造数字或据此做普遍性能排名。

WebGPU requires secure context (HTTPS/localhost) and compatible browser/adapter. WebGL2 remains available if WebGPU is unsupported. / 若 WebGPU 不支持，仍可单独运行 WebGL2。
